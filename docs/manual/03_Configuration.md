# Configuring SpitFW

SpitFW uses a tile-based configuration menu, designed to be intuitive and quick to navigate.

## How to access the configuration
To configure a SpitFW window, simply **tap the widget** on your radio's screen. The configuration menu will open.

## The Configuration Structure
The configuration is divided into layers:
1. **ROOT**: The main menu where you choose the category (Engine, Flight, Multi-Toggle, Other, Language).
2. **Category Page**: Where you select the specific instrument you want to configure.
3. **Instrument Page**: Where you activate the instrument and set its specific parameters.

*[IMAGE: Screenshot of the ROOT configuration page showing the five main tiles]*

## Navigating the Menu
- **Tiles**: To go deeper into the menu, simply tap on a tile (e.g., "ENGINE").
- **Back Arrow**: Every page has a "Back" tile in the top-left corner to return to the previous screen.

## Activating an Instrument
1. Navigate to the instrument you want to use (e.g., `ENGINE` -> `MAGS`).
2. At the top of the page, you will find a switch called **"Enable MAGS"** (or similar). Turn it ON.
3. The specific configuration fields for that instrument will appear below.

## Positioning Instruments (X/Y)
If you want to place an instrument in a specific position on the screen:
1. Inside the instrument's page, tap the **"X/Y"** tile at the top.
2. Turn ON the **"Use X/Y"** switch.
3. Enter the **X** (horizontal) and **Y** (vertical) coordinates.
4. Press Back. The instrument will move to the new position on your screen.

*[IMAGE: Screenshot of the X/Y setup page, showing the switch and the two number fields]*

## Changing the Language
1. Go back to the **ROOT** menu.
2. Tap the **"LANGUAGE"** tile.
3. Select your preferred language (English or Italian).
4. The entire widget will instantly update to the chosen language. 
*(Note: The language is global and applies to all SpitFW windows).*

# Introduction to SpitFW

## What is SpitFW?
SpitFW is a modular, highly customizable cockpit widget designed for **ETHOS** (FrSky radios). 
Originally created to reproduce the cockpit of a Spitfire, it has evolved into a flexible framework that allows you to build custom instrument panels for any model.

## Key Features
- **Modular Architecture**: Enable only the instruments you need.
- **Multiple Instances**: Create different windows (e.g., "Engine", "Flight", "Multi") on the same model, each with its own layout.
- **Vector Graphics**: Many instruments are drawn using code, keeping memory usage low.
- **Internationalization**: Full support for English and Italian.
- **Smart Telemetry**: The AFG (Fuel Gauge) can calculate fuel consumption based on throttle OR read a cumulative telemetry sensor.

# AFG – Fuel Gauge Configuration

AFG offers two operating modes: throttle-based fuel estimation and telemetry-based indication.

## 1. Mode Selection

Choose between the original estimation mode and telemetry mode.

## 2. Telemetry Configuration

Select the telemetry source and configure capacity and reserve.

## 3. Battery Configuration

Configure three battery capacities selectable through a physical three-position switch.

## 4. Estimation Configuration

Configure the original throttle-based estimation mode.
